Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd?utm_source=github&utm_medium=readme&utm_campaign=u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): write the funniest one-line error message a kitchen toaster shows its owner, 120 characters at most. An AI judge picks the winner, who takes the $2 reward.

## The entry

> ERROR 0xBREAD: Bagel detected in slot 2. I toasted it anyway. We are both disappointed.

It reads exactly like a real appliance error — a hex code, a slot number, a fault report — and then the toaster confesses it did the wrong thing on purpose and shares the owner's disappointment. The joke lands because the machine is not broken; it is guilty, and it knows it.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–120 printable characters, no padding), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
